# API directory placeholder

This root-level folder is not the active FastAPI package. API routers are under **`backend/app/api/`**, and the application includes them from **`backend/app/main.py`**.

Start the backend and use:
- `/docs` — Swagger UI.
- `/redoc` — ReDoc.
- `/openapi.json` — OpenAPI schema.

Read [API standards](../docs/APIStandards.md) and [backend setup](../backend/README.md). The running OpenAPI schema is authoritative for routes, schemas and security requirements.
