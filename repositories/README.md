# Repositories package placeholder

The active repository layer is under **`backend/app/repositories/`** and feature-specific packages in **`backend/app/`**. Repositories encapsulate persistence queries; business workflows and transaction orchestration belong in services.

See [Coding Standards](../docs/CodingStandards.md), [Database Standards](../docs/DatabaseStandards.md) and [architecture](../docs/Architecture.md).
