# Infrastructure directory orientation

The local development container topology and monitoring configuration live under **`docker/`**. Release deployment configuration and environment templates live under **`deploy/`**. CI/deployment workflows live under **`.github/workflows/`**.

This root-level directory is currently a placeholder. See [Docker guide](../docker/README.md), [deployment guide](../deploy/README.md), and [high availability guide](../docs/high-availability/README.md).
