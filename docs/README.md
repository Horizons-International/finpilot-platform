## Documentation conventions

- Treat code, migrations, environment templates, OpenAPI and the active CI workflow as the implementation source of truth.
- Static examples are illustrative. Confirm required fields, enum values, authorization and status codes against the current API schema.
- A guide describing a capability is not evidence that the capability has passed independent security, performance or production-readiness testing.
- Replace credentials and identifiers in examples with synthetic local values. Never add live secrets or real customer data to documentation.
